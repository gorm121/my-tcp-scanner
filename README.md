# High-Performance Network Scanner (Go)

[![Go Version](https://img.shields.io/badge/Go-1.22+-00ADD8?style=flat&logo=go)](https://golang.org/)
[![Platform](https://img.shields.io/badge/Platform-Windows-0078D6?style=flat&logo=windows)](https://microsoft.com)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Многопоточный асинхронный сканер портов и утилита сетевой разведки (Reconnaissance) на языке Go. Поддерживает сборку сырых TCP/IP пакетов (SYN Stealth Scan) через WinDivert, многопоточный TCP Connect скан, протокольно-ориентированный UDP скан, быстрое обнаружение хостов в подсетях (Host Discovery) и глубокий фингерпринтинг сервисов (SSH, TLS/SSL, HTTP, Redis).

---

## 🚀 Ключевые возможности

### 1. Режимы сканирования
- **SYN Stealth Scan (`-scan syn`)**:
  - Ручная побайтовая сборка заголовков IPv4 и TCP (RFC 793).
  - Вычисление 16-битных контрольных сумм псевдозаголовков (RFC 1071).
  - Использование драйвера **WinDivert** для отправки raw-пакетов и перехвата входящих `SYN-ACK`.
  - **Глушение исходящих `RST`**: драйвер перехватывает и отбрасывает системные сбросы Windows, делая скан скрытным (half-open).
  - Автоматический fallback на Connect-сканирование при запуске без прав Администратора.
- **TCP Connect Scan (`-scan connect`)**:
  - Высокопроизводительный пул воркеров на горутинах и каналах.
  - Полноценная установка соединений с настраиваемым таймаутом.
- **Protocol-Specific UDP Scan (`-scan udp`)**:
  - Data-driven архитектура без жестких `switch/case`.
  - Отправка специализированных бинарных полезных нагрузок (Payloads) для гарантированного отклика:
    - **DNS (53)**: валидный бинарный DNS A-query.
    - **NTP (123)**: 48-байтный запрос точного времени (RFC 5905).
    - **NetBIOS (137)**: Node Status запрос (извлекает имя ПК в Windows LAN).
    - **SNMP (161)**: `sysDescr` GetRequest с комьюнити `public`.
    - **SSDP / UPnP (1900)**: M-SEARCH запрос для IoT и роутеров.
    - **MSSQL Browser (1434)**: обнаружение экземпляров SQL Server.
    - **TFTP (69)** & **mDNS (5353)**.

### 2. Обход средств обнаружения (Anti-IDS / Stealth)
- **Source Port Randomization**: каждый отдельный SYN-пакет выстреливается с уникального случайного порта источника в диапазоне `40000–65000`.
- **Destination Port Shuffling**: перемешивание целевых портов (`rand.Shuffle`) для размытия паттернов сигнатурного анализа IDS/IPS (Snort, Suricata).
- **Stateless SYN-Cookies**: генерация и проверка sequence number через `seq := port ^ secretKey`, исключающая влияние мусорного сетевого трафика.

### 3. Разведка подсетей (CIDR & Host Discovery)
- **Поддержка CIDR (`-target 192.168.1.0/24`)**: быстрое побитовое развертывание подсети любого размера через `uint32`.
- **Умный пред-пинг (`-discover`)**: параллельная проверка хостов по популярным портам (`80, 443, 445, 22, 135`).
- **RST-эвристика**: хост признается живым не только при открытом порте, но и при ответе `connection refused` (RST от ОС).

### 4. Глубокий фингерпринтинг (Banner Grabbing)
- **SSH (22)**: определение ОС и точной версии демона (`SSH-2.0-OpenSSH_9.6p1 Ubuntu`).
- **HTTPS / TLS (443, 8443)**: чтение SSL-сертификатов без прерывания на self-signed ошибках. Извлечение **Common Name (CN)** и альтернативных имен **SAN (Subject Alternative Names)** для поиска скрытых поддоменов.
- **HTTP (80, 8080, 8000)**: извлечение тега `<title>` и заголовка `Server:`.
- **Redis (6379)**: проверка доступности без пароля.

### 5. Надежность и архитектура
- **Graceful Shutdown**: мгновенная отмена всех горутин и сокетов по `Ctrl+C` через `signal.NotifyContext` и неблокирующие `select`.
- **Чистый Pipeline**: полная координация воркеров на паттерне закрытия каналов («эффект домино») без висящих горутин и утечек сокетов.

## 📁 Структура проекта

```text
my-tcp-scanner/
├── main.go          # CLI флаги, запуск сканирования, итоговый отчет
├── syn_scan.go      # Логика WinDivert, сниффер и raw SYN-отправитель
├── raw_packet.go    # Побайтовая сборка IPv4/TCP заголовков и контрольные суммы RFC 1071
├── connect_scan.go  # Пул воркеров для многопоточного TCP Connect сканирования
├── udp_scan.go      # Табличный UDP-движок и генераторы бинарных полезных нагрузок
├── target.go        # Парсинг CIDR, диапазонов портов, DNS и Host Discovery
├── probe.go         # Сервисный фингерпринтинг (SSH, TLS certs, HTTP Title)
├── WinDivert.dll    # Библиотека драйвера WinDivert (Windows)
└── WinDivert64.sys  # Драйвер ядра WinDivert
```

## 🛠 Установка и сборка

Требуется **Go 1.22+** и ОС **Windows** (для режима WinDivert).

1. Клонируйте репозиторий:
   ```powershell
   git clone https://github.com/gorm121/my-tcp-scanner.git
   cd my-tcp-scanner
   ```

2. Убедитесь, что файлы `WinDivert.dll` и `WinDivert64.sys` находятся в папке с программой.

3. Скомпилируйте бинарник:
   ```powershell
   go build -o my-tcp-scanner.exe .
   ```

## 📖 Примеры использования

> [!IMPORTANT]
> Для использования режима **SYN-сканирования (`-scan syn`)** терминал должен быть запущен **от имени Администратора**. Режимы `connect` и `udp` работают с правами обычного пользователя.

### 1. Быстрый скрытный SYN-скан хоста (топ порты)
```powershell
.\my-tcp-scanner.exe -target 192.168.1.1 -p 22,80,443,8080 -scan syn
```

### 2. Сканирование диапазона портов с определением баннеров
```powershell
.\my-tcp-scanner.exe -target scanme.nmap.org -p 1-1024 -scan connect -timeout 1000
```

### 3. Разведка подсети с предварительным обнаружением хостов (Ping)
```powershell
.\my-tcp-scanner.exe -target 192.168.0.0/24 -p 80,443 -discover -scan syn
```

### 4. Сканирование UDP-сервисов
```powershell
.\my-tcp-scanner.exe -target 8.8.8.8 -p 53,123,161 -scan udp -timeout 1000
```

## ⚙️ Параметры командной строки

| Флаг | По умолчанию | Описание |
| :--- | :--- | :--- |
| `-target` | `127.0.0.1` | Целевой IP-адрес, доменное имя или подсеть CIDR (например, `192.168.1.0/24`) |
| `-p` | `1-1000` | Список портов через запятую и/или диапазоны (`22,80,443` или `1-65535`) |
| `-scan` | `syn` | Режим работы: `syn` (WinDivert raw-пакеты), `connect` (TCP) или `udp` |
| `-t` | `50` | Количество параллельных воркеров (потоков) |
| `-timeout`| `500` | Таймаут ожидания ответа в миллисекундах (для внешних сетей рекомендуется `1000-1500`) |
| `-rate` | `1` | Задержка между отправкой SYN-пакетов в мс (для syn-режима) |
| `-discover`| `false` | Включить предварительный поиск активных хостов в подсети перед сканированием |
| `-no-banner`| `false` | Отключить снятие баннеров и фингерпринтинг сервисов |
